# assets — 게임 에셋

아트·사운드 산출물이 들어오는 디렉터리. 현재(D1~D2)는 비어 있는 것이 정상이다 —
부트스트랩 장면은 코드 생성 지오메트리만 사용한다.

| 하위 폴더 | 내용 | 담당 산출물 | 도착 시점 |
|---|---|---|---|
| `models/` | 로우폴리 모델 (잠수함·화물선·구축함, 각 2,000트라이 이하) | 그래픽 디자이너 | D+8 |
| `audio/` | 사운드 세트 (소나·폭뢰·엔진음) | 사운드 디자이너 | D+10 |
| `textures/` | 텍스처 (플랫 셰이딩 원칙상 최소한만) | 아트팀 | 필요 시 |

## 규칙

- 초기 다운로드 15MB 게이트(G2)를 침식하지 않도록, 사운드는 초기 번들에서
  제외하고 스트리밍 후속 로드한다 (마스터 플랜 §12.1).
- 제외 범위 콘텐츠(어군·장식 오브젝트 등 §6.3)의 에셋을 추가하지 않는다.
- 바이너리 에셋은 `.gitattributes`에 등록된 확장자만 사용한다.
