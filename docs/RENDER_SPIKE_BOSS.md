# RENDER_SPIKE_BOSS — 보스 분절 애니메이션 기술 스파이크 판정

> PvE 1주차 스파이크 (11차 개발팀 소회의 결의 5, 리스크 R-P1).
> 담당: 그래픽스. 스파이크 코드: `src/render/boss/` (기본 장면과 격리).
> 실행: `?bossSpike=1` / B안: `?bossSpike=1&bossMotion=b` (기본 비활성).

## 1. 판정 질문 (사전 정의)

| # | 질문 | 근거 |
|---|---|---|
| ① | 거대 생물처럼 위협적으로 보이는가 | 6차 결의 6 '군함을 잡아먹은 놈' |
| ② | 우스꽝스러운 분절 움직임으로 보이지 않는가 | 11차 결의 5 스파이크 조건 |

## 2. 기술 구성 (결의 준수 확인)

- **강체 5분절 계층 트랜스폼**: 머리·턱·몸통·꼬리기부·꼬리지느러미(+가슴
  지느러미 쌍, 등지느러미는 몸통 고정). 스켈레탈·스키닝·관절 물리 **없음** —
  기존 씬 그래프 회전만 사용 (결의 5 절충안 그대로).
- **사인파 위상차**: 꼬리기부 → 꼬리지느러미로 위상 지연을 줘 파도가 몸을
  타고 흐르는 유영. 머리는 몸통 반대 위상(시선 유지). 진폭·주기는
  `renderVisualParams.json bossSpike`(순수 연출값).
- **물리 충돌체는 게임플레이 소유 단일 캡슐** 전제 유지 — 이 모듈은 시각
  전용, AI·체력 임계값·판정 계산 없음. 스파이크의 순찰 이동은 QA 시연
  경로이며 본통합 시 보스 AI 포즈 소비로 교체.
- **약점·단계 연출 연결점** (안건 D): `setWeakpointActive(bool)` → 배 아래
  플레이트 발광 점멸 + 턱 개방 / `setPhase(1~3)` → 체색·발광 전환 +
  `onPhaseTransition` 콜백 시임(파티클·카메라 연출 본구현 D17~20 연결점).
  활성·단계 값은 게임플레이가 소유 — 스파이크 자동 순환은 QA 시연 값.

## 3. 판정 결과: **성공 (조건부)** — B안 발동 불필요, 모션 리뷰 1건 잔여

- 실측(헤드리스 Chromium + SwiftShader, 실키 입력, 연속 10프레임 시퀀스):
  - ① 위협감: **충족** — 보스(전장 약 30m)가 잠수함 머리 위·협곡 사이를
    통과하는 컷에서 화면 상단을 가득 채우는 압도적 스케일 확인
    (판정 컷: 작업 로그 bj_03). 로우폴리 플랫 셰이딩과 실루엣 정합.
  - ② 우스꽝스러움: 스틸·연속 프레임 기준 **분절 경계가 두드러지지 않음** —
    위상차 유영이 '기계적으로 굽는' 로우폴리 스타일로 읽힘. 단, 최종 판정
    항목이 '움직임의 인상'이므로 **실기 60fps 모션 리뷰(리드·아트팀장 확인)를
    조건**으로 남긴다.
- 성능: 분절 7메시 + 약점 1 = 드로우 +8, 스키닝 0 — FPS 오버레이 기준
  기존 장면과 차이 없음 (내장그래픽 재계측은 D+9 빌드에서).

## 4. B안 경계 (실패 시 이관 경로 — 준비 완료, 기본 비활성)

- `BossMotionStyle` 인터페이스로 이동 표현을 격리 — A안
  `SegmentedSwimMotion`(유영 순찰), B안 `BossMotionFallback`(목표점 급가속
  대시 + 관성 활공 감속 + 근접 통과 카메라 흔들림 훅 `onNearPass`).
- 모션 리뷰에서 ②가 실패 판정되면: B안 활성 + 분절 진폭 0 설정으로 전환
  (이관 공수 0.5일 — 결의 5 확정 경로). `&bossMotion=b`로 즉시 비교 가능.

## 5. 본통합(D10~16) 시 재확인 항목

1. 보스 AI(리드) 포즈·상태 소비로 QA 순찰 이동 교체 — 시각/판정 경계 유지.
2. 약점 활성·단계 값의 정식 상태 소스·이벤트 계약 (INTEGRATION_NOTES 경유).
3. 보스 전장 엄폐물은 EnvironmentDressing 예산 **재배분**(신규 밀도 금지 —
   11차 결의 1).
4. 단계 전환 파티클·카메라 연출은 onPhaseTransition 시임에 연결 (D17~20).
