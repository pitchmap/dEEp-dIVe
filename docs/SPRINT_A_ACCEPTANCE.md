# SPRINT_A_ACCEPTANCE — 스프린트 A 인수 기준과 검증 방법

> 근거: 7차 대회의(`meetings/12`) 결의 3·5 / 개발 소회의(`meetings/13`) 결의 1·3·4·5
> + 보완분 결의 7·8·9 / 스프린트 A 실행 소회의(`meetings/14`) 결의 3.
> 실행: `npm run verify:sprint-a` (자동 항목 + 수동 확인 목록 분리 출력).

## 판정 규칙

- **A는 전 항목이 핵심 게이트다** (소회의 13 결의 1) — A1~A8 중 하나라도
  미달이면 스프린트 A 미완료이며 **B 브랜치 병합 금지**.
- 판정은 각 창의 로컬이 아니라 **dev 통합 빌드**에서 한다 (소회의 14 결의 3).
  병합 순서: 리드 → 게임플레이 → 그래픽스 → **툴링(검증자 마지막)**.
- A5는 **A5-T1~T6 저장 실패 롤백 시나리오까지 포함**해야 통과다 (보완분 결의 7).

## 자동 / 수동 구분

`verify:sprint-a`는 관측 대상이 실제로 존재하는 항목만 pass/fail로 판정하고,
아직 병합되지 않은 창의 산출물에 의존하는 항목은 **수동 확인 목록**으로 뺀다.
비어 있는 코드에 맞춘 '가짜 초록불'을 만들지 않기 위한 규칙이다.

| 항목 | 내용 | 현재 판정 방식 |
|---|---|---|
| A1 | 전 심도 조준 진입 (최소 3개 심도) | 파라미터에 심도 조건 부재 = 자동 / 런타임 3구간 진입 = **수동**(게임플레이 병합 후) |
| A2 | 조준 전·후·해제 시 Y 동일, 조준이 수직 속도를 만들지 않음 | reset 규격 = 자동 / Y·수직 속도 비교 = **수동** |
| A3 | 조준 카메라 forward = 어뢰 초기 forward (동일 소켓), spawn 자기 충돌 없음 | 오프셋 중복 정적 검사 준비 = 자동 / dot·충돌 = **수동**(리드 2소켓 병합 후) |
| A4 | 기지·해역 UI 크레딧·희귀 부품 표시가 실제 상태와 일치 | **수동**(그래픽스 UI 병합 후) |
| A5 | 구매 성공·실패, 실패 사유 5종, **T1~T6** | 저장 원자성 T1~T6·안내 구분 = 자동 / UI 사유 표시 = **수동** |
| A6 | 장비 장착·교체·해제 | 저장·롤백 = 자동 / UI 조작 = 수동(A5-ui에 포함) |
| A7 | 구매·장착 후 새로고침 상태 유지, 출항 전 저장 | 자동 (저장 매체 재로드로 새로고침 재현) |
| A8 | 임시 경제·장비 수치 전량 공식 params 이관 | 자동 (미확정 필드·잔여 provisional 목록 출력) |
| §8 | '전 심도 조준(구 심도 전용 규칙 폐기)' 계열 표현이 현재 문서·규약·테스트·주석에 없음 | 자동 (회의록·마스터 플랜은 역사 기록으로 별도 분류) |

## A5-T1~T6 (저장 실패 롤백)

| ID | 시나리오 | 기대 |
|---|---|---|
| T1 | 충분한 크레딧 | 구매·저장 모두 성공, 저장에 반영 |
| T2 | 크레딧 부족 | 상태 무변경, `kind: 'rejected'` + 사유 |
| T3 | 저장 실패(write) | 크레딧 롤백 |
| T4 | 저장 실패(quota 유사) | 업그레이드 단계 롤백 |
| T5 | 실패 후 새로고침 | 구매 전 상태 유지 |
| T6 | 안내 구분 | `rejected`(불가 사유 5종) vs `saveFailed`(고정 문구) |

실패 주입은 `src/meta/save/FaultInjectingStorage.ts`(테스트 전용 어댑터)가
담당한다 — 쓰기 실패 / 백업 쓰기 실패 / quota 유사 / 직렬화 실패 4종.
`defaultSaveStore`(프로덕션 기본 경로)는 실제 localStorage를 쓰므로 이 어댑터를
거치지 않는다.

## 구매 불가 사유 5종 [7차 결의 7]

크레딧 부족 / 희귀 부품 부족 / 최대 단계 / 슬롯 부족 / 이미 장착 중.
**미구현 기능의 사유 문구(예: 선행 업그레이드 미충족)는 코드·UI 모두 금지.**
판정 자체는 게임플레이 소유이며, 툴링은 결과를 저장 트랜잭션에 실어 나른다.

## 저장 실패 안내 문구 [보완분 결의 7 — 고정]

> 저장에 실패하여 구매가 취소되었습니다. 저장 공간 또는 브라우저 설정을 확인해주세요.

내부 예외 문자열(QuotaExceededError 등)은 사용자 화면에 노출하지 않는다.
원인은 개발 로그(SaveStore)에만 남는다.

## 가격 검증 기준 [7차 결의 8]

보스 도전 최소 사양까지 **예상 출항 4~6회**. 업그레이드 시뮬레이터의
'총비용 / 출항당 평균 크레딧' 입력으로 사전 확인한다. 미확정(null) 값이
하나라도 있으면 **판정 보류** — 임의 값을 대입해 곡선을 만들지 않는다.

## 범위 밖 (이번 스프린트에서 검증하지 않음)

어뢰 캠 / 보스 테스트.
