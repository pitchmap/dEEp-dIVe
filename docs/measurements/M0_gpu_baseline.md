# M0 GPU 기준선 실측 (내장그래픽 노트북 2대)

> 작성: 그래픽스 창. **실측하지 않은 수치는 기재하지 않는다** — 실기기 칸이
> 비어 있으면 미실측이다. 이 문서의 GPU 표는 빌드·툴 담당자와 목표 기기
> 2대에서 실측 후 채운다. 본 저장소 작업 환경(원격 컨테이너)은 swiftshader
> (소프트웨어 렌더)뿐이라 **실기기 GPU 수치를 생성할 수 없다** — §D의
> swiftshader 수치는 회귀 비교용 참고이며 GPU 판정 근거가 아니다.

기준 커밋: dev `d968514` (M0 병합 tip)

## A. 측정 절차 (재현 규격)

- 빌드: `npm run build` 후 `dist/` 정적 서빙 (dev 모드 아님 — HMR 오버헤드 배제)
- 해상도 1280×720 창모드, 브라우저 하드웨어 가속 켜짐 확인
  (`chrome://gpu`에서 SwiftShader 아닌 실제 GPU 확인 — SwiftShader로 잡히면
  그 수치는 이 표에 기재하지 않는다)
- 품질: URL `?quality=low` / (기본=medium) / `?quality=high`
- 각 시나리오 60초 주행, FPS는 성능 오버레이의 **평균 FPS**(부팅 직후 3초
  제외), 드로우 콜·삼각형은 오버레이 `draw`·`tri` 값
- GPU 메모리: `chrome://gpu` 또는 작업 관리자(GPU 프로세스)로 기록,
  참고로 텍스처 상주 추정치는 §C 참조
- 시나리오
  1. **협곡 일반 주행** — 출항 → 순항 심도(y=0)에서 수로 왕복 60초
  2. **폭뢰 피격 전투** — 화물선 격침 → 발각 상태 유지(전속) → 폭뢰
     피격·침수 구간 60초 (기포·wake·플래시 활성 상태)
  3. **심해 하강** — 수면(y≈11) → 최심부(y≈-19) 왕복 (심도 그레이딩 전 구간)

체크 항목(각 조합에서): 텍스처 404/fallback 발생 여부(콘솔 경고
`[sceneTextures]`), 안개·조명·텍스처·암벽 셸 이상, 새 잠수함 모델(이중 도장·
덕트 프로펠러), 세력 마크(태그·선박 데칼), 탐조등(빔·조명), 프로펠러 wake.

## C. 정적 예산 (코드 기준 — 실측 아님, 산출 근거 명시)

- 텍스처 상주 추정 (비압축 RGBA + mip ×1.33):
  - medium/high: 암벽 1024² + 퇴적물 1024² (각 ~5.6MB) + 금속 512² +
    마크 아틀라스 512×256 (~1.4MB + ~0.7MB) ≈ **13.3MB**
  - low(512 상한): ≈ **4.9MB**
- 파티클 상한: 프로펠러 기포 60(low)/120(med)/170(high) · 부유물
  40/140/190 · 어뢰 기포 96 (전부 1드로우 풀)
- 실시간 광원: 방향광 1 + 탐조등 SpotLight 1(그림자 없음) — 전 품질 동일

## D. swiftshader 참고 수치 (원격 컨테이너 — **GPU 수치 아님**)

회귀 비교 전용. 1280×720, dev 모드, 3초 rAF/오버레이 평균:

| 구간 | 드로우 콜 | tri | 평균 FPS |
|---|---|---|---|
| M0 이전 기준(아트 패스 직후, 순항) | 58 | 12,772 | 17~18 |
| M0 tip 순항 (medium) | 65 | ~17.3k | 11.3~11.6 |
| M0 tip 순항 (low) | 58 | ~17.2k | 11.6 |
| M0 tip 최고속(기포·wake 활성) | 64 | ~17.8k | 11.4 |

텍스처 404 fallback: low/medium/high 전부 단색 복귀·오류 0 (M0 병합 검증에서 실측).

## E. 보스 전장 밀도 예산 (작업 4 — M1 대기)

- M0 기준선: 순항 드로우 **65** (위 §D — 실기기 기준선은 §B 실측 후 대체)
- 원칙(11차 결의 1): 보스 전장 데코는 EnvironmentDressing 예산의 **재배분**
  이며 추가가 아니다 — 산호 18개소·어군 2종·잔해 1·원경 1겹 예산 안에서 이동
- **현재 진행 불가**: M1 보스 전장 레이아웃(게임플레이 창)이 아직 없다.
  레이아웃 도착 시 재배분 후 M0 기준선 대비 드로우 콜 증분을 이 문서에 기록.
  기본 품질이 low로 확정되면 상한을 low 기준으로 재계산한다.
