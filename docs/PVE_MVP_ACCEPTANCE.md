## 루프 완주 판정

```
기지 진입 ✅ → 출항 ✅ → 정상 항해 ✅ → 함선 충돌 통과 없음 ✅
→ 비조준 발사 불가 ✅ → 우클릭 조준경 ✅ → 좌클릭 발사 ✅
→ 어뢰 모델·항적 ✅ → 적대 화물선 격침 ✅ → 크레딧 드롭·회수 ✅
→ 중립 공격 ⚠(중립 함선 미배치) → 경비함 요청 ⚠(발행 경로만, 스폰 없음)
→ 중도 귀환 ✅ → 정산 ✅ → 업그레이드 적용 ✅(구매 UI 없음)
→ 저장 ✅ → 새로고침 ✅ → 크레딧·희귀·업그레이드 유지 ✅
→ 재출항 ✅ → 업그레이드된 전투 수치 적용 ✅
```

**결론: 성장 루프는 종단간 성립한다.** 끊긴 고리는 ① 중립 함선 배치 +
경비함 스폰(AI 소비자), ② 업그레이드 구매·장비 장착 UI 두 곳이며,
둘 다 이번 통합 범위 밖(신규 기능·AI)이라 후속으로 남긴다.

## 보스 스파이크 판정 (D+9 Exit Criteria와 분리)

| 항목 | 상태 |
|---|---|
| 보스 분절 렌더 스파이크 | ✅ QA 스파이크로 유지 (`?bossSpike=1`, `&bossMotion=b`) — 자체 데모 순환 |
| 보스 약점 판정(게임플레이) | ✅ 구현·검증됨 (`BossWeakPointTarget`, 결정적 검증 포함) |
| 보스 AI·포즈 연결 | ❌ **의도적 미구현** — 이번 통합에서 구현하지 않음 (지시) |
| 보스 패턴 6종 | ❌ 미착수 (범위 밖) |

보스는 D+9 합격 판정에 포함하지 않는다.
