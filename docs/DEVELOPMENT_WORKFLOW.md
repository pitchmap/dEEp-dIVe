# DEVELOPMENT_WORKFLOW — D1~D15 단계와 Exit Criteria

> 마스터 플랜 §8 요약. 원칙 [확정]: **그래픽보다 조작이 먼저, 조작보다 계측이
> 먼저.** 각 단계는 Exit Criteria로만 완료 판정. 주간 빌드 D+5 / D+10 / D+15.

| 단계 | 기간 | 작업 | Exit Criteria (완료 조건) | 실패 시 대응 |
|---|---|---|---|---|
| **0. 환경 구축** | D1~D2 | Three.js+Vite+TS 생성 / 저장소·브랜치·구조 / 정적 배포 / fps·로딩 계측 오버레이 / JSON 툴 골격 / 빈 씬 배포 | 빈 씬이 URL로 접속되고 fps·로딩 시간이 화면에 표시 → 계측 오버레이 작동 확인(리드 승인) | D2 저녁 미완 → 수동 배포로 강등, D+5 전 재자동화 |
| **1. 회색 박스** | D3~D5 | 캡슐 잠수함 이동+관성 / 선회(잠수함 기준) / 심도 3층 / 카메라 회전·리센터·±60도 / 회색 협곡 블록아웃 | 전원 브라우저 조작 테스트 + 관성 1차 튜닝 완료 → D+5 리뷰 "조작이 씹힌다" 2인 미만 | 수치표 지연 → 임시 기본값 선진행(R7) / 조작 미완 → 자동 카메라만으로 축소 |
| **2. 코어 전투 루프** | D6~D9 | 화물선 경로 / 임시 탐지(인터페이스 분리 의무) / 수동 조준+보조선 / 어뢰 격침 / 구축함 2상태 / 폭뢰 3초 신관 / 탈출·클리어·실패 | 죽지 않고 1회 클리어 가능(전 구간) → 완주 시연(리드 판정) | **D9 미완 = R-D3 비상 컷** — 은신을 '소음+눈 아이콘'만으로 축소 (리드 단독 권한) |
| **3. 은신·탐지** | D10~D12 | DetectionSystem 본 구현 교체 / 파문 이펙트 / 지형 엄폐 / 심도 보정 / 발사 지점 노출 / 침묵 항행 / 눈 아이콘 3단계 | '은신 클리어'와 '들켜서 도주 클리어' 두 스타일 모두 성립 + D+10 리뷰 통과 | 파문 지연 → 임시 링 이펙트 대체 후 4단계 품질화 |
| **4. 연출 적용** | D13~D14 | 모델 3종 교체 / 심도별 포그·조명 / 폭뢰 사운드 3초 동기화 / X-ray 침수 / 최소 UI / 엔진음·소나음 연동 | **보호 목록 4종 작동: 60fps·폭뢰 동기화·X-ray 침수·파문** (4/4 검수) | 모델 지연 → 회색 박스 유지 채 게이트行 / X-ray 실패 → 아이콘 점멸 대체 [확정 경로] |
| **5. 통합·게이트 준비** | D15 | 최적화(성능 예산 §12) / 저사양 모드(희생 순서) / 상위 버그 수정 / **빌드 봉인** / G1·G2 자체 측정 | G1(60fps)·G2(3초·15MB) 자체 측정 통과 → 봉인 선언(리드) | G1 미달 → 희생 순서 ①~④ / G2 초과 → 사운드 스트리밍 분리·재압축 |

**D+16~20:** 테스터 5인 세션 (디렉터 주관, 2인+ 노트북 스피커) →
**D+21:** 게이트 리뷰 (4문 순차 통과제 — `docs/GATES.md`)

## 일상 워크플로 (모든 역할 공통)

1. `docs/CURRENT_STATUS.md`·`FILE_OWNERSHIP.md`·`INTERFACES.md` 읽기
2. 자기 `feat/*` 브랜치에서 작업 (`docs/BRANCHING.md`)
3. 수치는 `params/*.json`에서만, 계약 변경은 INTEGRATION_NOTES 경유
4. `npm run typecheck` + `npm run build` (+ `check:size`) 통과 확인
5. `CURRENT_STATUS.md` 자기 구역 갱신 → 커밋 (게이트 영향 시 `[Gx]` 태그)
6. feat→dev PR: 1인 리뷰 (로직·인터페이스 준수·하드코딩·게이트 태그 확인)
