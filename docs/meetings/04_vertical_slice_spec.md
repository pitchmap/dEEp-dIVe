## 안건 1. 버티컬 슬라이스 플레이 구간 확정

**박태현:** "제안 구간은 문서대로 — 출항 → 탐지 → 은신 → 어뢰 → 구축함 등장 → 폭뢰 회피 → 탈출. 이 한 사이클이면 코어 루프 전부 검증됩니다. 플레이타임은 **5분**을 밀겠습니다. 10분이면 3주 안에 밀도를 못 채우고 늘어진 5분이 됩니다."

**최윤아:** *(반대)* "5분은 너무 짧습니다. 은신의 긴장은 '시간을 들여 기다리는' 데서 나오는데, 5분 안에 출항부터 탈출까지 넣으면 은신 구간이 40~50초밖에 안 남아요. 그건 UBOAT의 긴장이 아니라 Submarine Attack의 슈팅 템포죠. 저는 8~10분."

**서지우:** "구조로 절충합시다. **목표 7분, 상한 10분.** 단 은신·회피 구간은 플레이어 실력에 따라 늘어나는 가변 구간으로 설계 — 잘하면 7분, 발각당해 쫓기면 10분. 시간이 늘어나는 것 자체가 페널티이자 드라마가 되게."

**최종 목표/실패 조건 논의:**

**박태현:** "최종 목표는 **화물선 격침 후 탈출 지점 도달**. 격침만으로 끝나면 '공격 후 도주'라는 잠수함 게임의 후반 긴장이 통째로 날아갑니다. 실패 조건은 단순하게 **선체 내구도 0 = 파괴** 하나만. 산소 고갈은 버티컬 슬라이스에선 '심해 은신 층에 오래 머물면 산소가 줄어드는 압박 요소'로만 쓰고, 그 자체로 사망까지는 안 가게."

**이준호:** "동의하는데 '발각 상태 유지'를 실패 조건에서 빼는 건 확실히 해두죠. 발각은 실패가 아니라 **국면 전환**이어야 합니다. 발각되는 순간 BGM이 바뀌고 구축함이 달려오는 — 실패가 아니라 2막의 시작."

**해역:** 전원 이견 없이 **협곡 해역** 확정 (풀 3D 지형 + 지형 은신 동시 검증).

> **결의 1:** 구간 = 출항→탐지→은신→어뢰→구축함→폭뢰 회피→탈출 / 목표 7분·상한 10분(은신·회피 가변) / 목표 = 화물선 격침 + 탈출 지점 도달 / 실패 = 내구도 0 단일 / 산소는 심해 층 압박 요소 / 해역 = 협곡

## 안건 2. 조작 방식 최종 확정

**박태현:** "이동은 **WASD**. W/S 전진·감속, A/D 선회. 마우스 클릭 이동은 잠수함의 '육중함'과 안 맞습니다. 그리고 여기가 UBOAT 레퍼런스가 진짜 들어갈 자리인데 — **관성**입니다. W를 떼도 바로 안 멈추고, 선회도 반 박자 늦게 도는. 이 묵직함이 잠수함 조작감의 전부예요."

**한도윤:** *(강한 반대)* "관성 반대합니다. 우리 유저는 브라우저 게임 유저예요. Submarine Attack이 890표에 4.4점을 받는 이유는 누르면 바로 반응하기 때문입니다. 관성은 '조작감이 무겁다'가 아니라 '조작이 씹힌다'로 느껴질 겁니다. 60초 게이트도 위험해져요."

**박태현:** "관성 없는 잠수함은 잠수함이 아니라 물속 비행기입니다. 이건 못 물러섭니다."

**서지우:** "수치로 중재합니다. **관성은 넣되 UBOAT의 절반 이하로.** 정지까지 1.5초, 90도 선회 2초 수준 — '묵직하지만 답답하지 않은' 지점을 버티컬 슬라이스에서 튜닝하고, 테스터 피드백에서 '조작이 씹힌다'는 응답이 2명 이상이면 태현 님이 관성치를 양보하는 조건부로."

**박태현:** "…그 조건이면 받습니다."

**나머지 항목 (합의 빠름):**
- 선회 기준: **잠수함 방향 기준** (카메라 기준이면 카메라 돌릴 때마다 조작이 뒤집힘 — 전원 동의)
- 부상/잠항: **Shift(부상) / Ctrl(잠항)**, 층 단위 이동
- 심도 층: **3개 확정** (잠망경/순항/심해 은신) — 문서 권고대로, 4개 이상은 학습 부담
- 카메라: 마우스 자유 회전(상하 ±60도 제한), **Space = 리센터**(잠수함 후방 뷰)
- 어뢰 조준 중: **카메라 자동 고정**(조준 뷰로 전환) — 조준과 카메라 조작을 분리해서 60초 게이트 방어
- 첫 판: **자동 카메라 모드**(리스크 로그 R2 채택), 2판부터 자유 카메라

> **결의 2:** WASD + 약한 관성(정지 1.5초, 조건부 튜닝) / 잠수함 기준 선회 / Shift·Ctrl 층 이동 / 심도 3층 / 카메라 자유 회전 ±60도 + Space 리센터 / 조준 중 카메라 고정 / 첫 판 자동 카메라

## 안건 3. 은신·발각 시스템 구체화

**박태현:** "문서의 단순화 공식을 그대로 규칙화합니다.
- **소음 증가:** 고속 이동(+대), 어뢰 발사(+중, 일시), 능동 소나 사용(+대, 일시)
- **탐지 감소:** 저속 항행(-), 심해 층(-), 지형 엄폐(시선 차단 시 탐지 정지)

발각 판정은 소음 수치 × 거리 × 심도 보정으로 계산되는 **탐지 게이지** 하나로 통합. 게이지가 차면 발각."

**최윤아:** "지형 엄폐 하나만 강하게 짚겠습니다. **지형이 시선을 막으면 탐지 게이지가 오르지 않는 것**은 협곡 해역의 존재 이유입니다. 이게 없으면 협곡은 그냥 예쁜 벽이에요. 단, 소리는 지형을 돌아가니까 능동 소나에는 엄폐가 안 통하는 걸로 — 시각 탐지는 차단, 음향 탐지는 감소만."

**이준호:** *(강한 반대 — 어뢰 노출 문제)* "어뢰 발사 시 위치 노출, 저는 '일시 +중'으로는 부족하다고 봅니다. **어뢰를 쏘면 무조건 대략 위치가 노출**되어야 해요. 이유는 게임 리듬입니다 — '쏘는 순간 사냥꾼에서 사냥감으로 바뀐다'는 국면 전환이 이 게임의 심장인데, 소음 관리를 잘하면 쏘고도 안 들킬 수 있다? 그럼 2막(폭뢰 회피)이 아예 발생 안 하는 판이 나옵니다. 버티컬 슬라이스에서 구축함 파트가 스킵되면 검증이 안 돼요."

**박태현:** "시스템 순수성으로는 반대지만… 버티컬 슬라이스 검증 관점은 인정합니다. 절충 — **어뢰 발사 = 발사 지점이 구축함에게 무조건 노출**(마지막 목격 위치로 기록). 단 노출되는 건 '발사한 그 지점'이지 현재 위치가 아니라서, 쏘자마자 이동하면 벗어날 수 있게. 국면 전환은 보장되고 플레이어 숙련도 여지도 남습니다."

**이준호:** "그거면 완벽합니다."

**UI:** 탐지 게이지는 눈 모양 아이콘 하나 — 비어 있음(안전) → 노란 반개(수색 중) → 빨간 완전 개안(발각). 침묵 항행 모드(엔진 정지, 이동 불가, 소음 최소)는 **토글 키 C**, 사용 중 배터리 미소모·산소만 소모.

> **결의 3:** 탐지 게이지 단일화(소음×거리×심도) / 지형 엄폐 = 시각 탐지 차단·음향은 감소 / **어뢰 발사 지점 무조건 노출**(마지막 목격 위치 방식) / 침묵 항행 토글 C / 눈 아이콘 3단계 UI

## 안건 4. 어뢰 전투 방식 확정

**서지우:** "여기가 Submarine Attack 레퍼런스의 본진입니다. 그 게임의 미덕은 단순함이에요 — 보이면 쏘고, 맞으면 터진다. 우리 어뢰 전투의 '첫 경험'은 그 즉각성을 그대로 가져옵니다."

**박태현:** "문서 권고안 기반으로 확정안 제시합니다.
- 적: **화물선 1종 + 구축함 1종**
- 어뢰: **3발**, 재장전 20초 (어뢰수 스킬로 단축)
- **첫 번째 적(화물선): 자동 포착** — 잠망경 심도에서 조준 키(우클릭)를 누르면 자동 락온, 리드샷 보조선 표시, 발사만 하면 명중권. Submarine Attack처럼 '일단 쏘는 재미'를 60초 안에 보장
- **이후: 수동 조준** — 보조선은 유지하되 락온 없음, 적 속도를 보고 직접 리드
- 화물선: 1발 격침 / 구축함: 2발 (버티컬 슬라이스에서 구축함 격침은 고난도 보너스)"

**김세라:** *(반대)* "자동 포착에 반대합니다. 첫 어뢰가 자동이면 유저가 배우는 건 '우클릭+발사'지 리드샷이 아니에요. 두 번째 적부터 갑자기 수동이 되면 '아까는 됐는데 왜 안 맞지'가 되고, 그건 튜토리얼이 아니라 배신입니다."

**박태현:** "그래서 중간 단계를 넣습니다 — 첫 발은 완전 자동 락온, **두 번째 발부터는 '조준선이 정답 위치에 가까워지면 색이 변하는' 반자동**. 세 번째부터 색 힌트도 제거. 자동 → 힌트 → 수동, 3단계 페이드아웃."

**김세라:** "페이드아웃 방식이면 철회합니다."

**이준호:** "사운드 요구 하나 — 어뢰 명중은 Submarine Attack처럼 즉각적이고 과장된 폭발음으로. 여기만큼은 리얼리즘 버리고 '뻥' 하는 손맛으로 갑니다. 수중 물리적으론 틀렸지만 상관없어요."

> **결의 4:** 화물선·구축함 각 1종 / 어뢰 3발·재장전 20초 / 조준 3단계 페이드아웃(자동 락온→색 힌트→수동) / 리드샷 보조선 상시 / 화물선 1발·구축함 2발 / 명중음은 아케이드식 과장

## 안건 5. 폭뢰 회피와 적 AI 설계

**박태현:** "구축함 AI는 상태 기계 4개면 충분합니다. **순찰 → 경계(마지막 목격 위치로 이동 + 소나 핑) → 공격(예상 위치 통과하며 폭뢰 투하) → 상실(일정 시간 미탐지 시 수색 범위 확대 후 순찰 복귀).** UBOAT의 AI를 뼈대만 발라낸 구조입니다."

**이준호:** "폭뢰 규칙, 1차 회의 아이디어를 공식 확정합니다.
- **풍덩(입수음, 방향 패닝) → 3초 → 폭발.** 이 3초가 우리 게임의 시그니처 리듬
- **화면 밖 폭뢰도 소리만으로 회피 가능** — 이게 '사운드 = 1차 정보' 원칙의 최종 시험대입니다
- 심도가 깊을수록 폭뢰 도달이 늦어져 회피 시간 +1초 (심해 층의 보상)
- 직격 = 대미지 대 + 침수 발생 / 근접 = 대미지 소 + **충격으로 잠수함이 밀려남**(UBOAT식 물리 연출, 카메라 흔들림 동반)"

**최윤아:** *(반대 1건)* "'플레이어 예상 위치로 이동'은 버티컬 슬라이스에선 빼죠. 예측 AI는 튜닝 지옥입니다. 3주 안에 하면 '귀신같이 따라오는' 이상한 AI가 나와요. 경계 상태에선 마지막 목격 위치 + 진행 방향 직선 연장, 딱 거기까지만."

**박태현:** "동의. 예측은 정식 개발로 이월."

> **결의 5:** 상태 기계 4단계 AI(예측 이동 제외, 직선 연장까지만) / 풍덩→3초→폭발 확정 / 화면 밖 폭뢰 소리 회피 가능 / 심해 층 회피 시간 +1초 / 근접 폭발 = 밀려남 물리 + 카메라 흔들림

## 안건 6. 승무원 4명의 실제 기능 결정

**박태현:** "문서 표 그대로 채택 제안 — 함장(긴급 회피: 3초간 선회·속도 증가), 소나수(주변 적·폭뢰 위치 표시 5초), 기관장(침수·손상 긴급 수리), 어뢰수(재장전 20초→8초). 전부 **버튼형(1~4키)**, 쿨다운 45~90초."

**김세라:** "X-ray 연출 관련해서 오늘 확실히 격상시키고 싶습니다. X-ray는 장식이 아니라 **정보**여야 합니다. UBOAT에서 침수가 무서운 이유는 물이 차오르는 게 '보이기' 때문이에요.
- 침수 발생 → X-ray 자동 발동, 해당 구획에 물이 차오르는 게 보임
- 기관장 스킬 사용 → 기관장 미니어처가 실제로 그 구획으로 뛰어가서 수리
- 어뢰 재장전 중 → 어뢰수가 어뢰를 미는 모션
즉 **스킬을 쓸 때마다 승무원이 '일하는 게 보이는' 것**. 이게 로우폴리 디오라마의 승부처입니다."

**한도윤:** *(우려)* "방향은 아름다운데 3주 스코프에서 미니어처 애니메이션 4종 + 침수 시뮬은 무겁습니다."

**김세라:** "우선순위 자릅니다. **침수 X-ray(자동 발동)가 1순위** — 이건 게임 정보라 필수. 승무원 이동 모션은 2순위 — 못 하면 해당 구획에 승무원 아이콘 점멸로 대체. 이 컷라인이면?"

**한도윤:** "그 컷라인이면 갑니다."

**승무원 행동불능 여부:** 박태현 — "버티컬 슬라이스에선 없음. 부상 시스템은 스코프 가드(영구 성장 없음 원칙)와 함께 정식 개발에서 재론." 이견 없음.

**판 내 강화:** 격침 보상으로 3택 1 카드(어뢰 +1 / 수리 쿨다운 -20초 / 최고 속도 소음 -1단계) — 버티컬 슬라이스에서는 화물선 격침 시 1회만 등장.

> **결의 6:** 4인 스킬 버튼형(1~4키), 쿨다운 45~90초 / X-ray = 게임 정보로 격상, 침수 표시 1순위·승무원 모션 2순위(아이콘 대체 허용) / 행동불능 없음 / 판 내 강화 3택 1 카드 1회

## 안건 7. UI와 정보 전달 방식

**위험 시에만 (화면 중앙부, 강조):** 탐지 게이지(눈 아이콘 — 수색 중부터 표시), 폭뢰 위험 방향(화면 가장자리 붉은 호), 침수 경고(X-ray 자동 발동), 산소(심해 층 체류 시에만)
**항상 숨김, 요청 시(Tab):** 소음 수치 상세, 목표·탈출 지점 방향"

**박태현:** *(반대 1건)* "소음 수치를 Tab 뒤로 숨기는 건 반대입니다. 은신 게임에서 자기 소음은 체감 정보 그 자체인데."

**한도윤:** "숫자로 보여주는 순간 시뮬레이터가 됩니다. 대안 — 소음을 UI가 아니라 **월드로** 보여주죠. 잠수함 주변에 소음 크기만큼 퍼지는 동심원 파문(소나 웨이브 이펙트). 조용하면 파문이 거의 없고, 전속이면 크게 퍼지는. 숫자 없이 직관적이고, 로우폴리 스타일에도 예쁘게 얹힙니다."

**박태현:** "…그건 반대 못 하겠네요. 채택."

**이준호:** "그 파문, 소리와 동기화합시다. 파문이 커질 때 엔진음도 커지게. 시청각 일치."

> **결의 7:** 3계층 UI(상시/위험 시/Tab) / 소음은 숫자 대신 **월드 파문 이펙트**로 표현(사운드 동기화) / 폭뢰 방향은 화면 가장자리 붉은 호

## 안건 9. 성능 목표와 기술 범위 확정

**한도윤:** "60fps 예산을 미리 자릅니다.

- 실시간 조명: **최대 2개** (태양 방향광 1 + 서치라이트/폭발 겸용 1)

- 로딩: 초기 다운로드 **15MB 이하** (접속 3초 사수), 사운드는 스트리밍 후속 로드"

**김세라:** "'희생 순서'를 미리 문서화하는 것에 강력 찬성합니다. 개발 후반에 '뭘 뺄까' 싸움이 제일 소모적이에요. 단 하나 — 파문 이펙트는 3순위가 아니라 보호 목록으로 옮겨주세요. 안건 7에서 소음 UI를 통째로 이 이펙트에 걸었잖아요. 이게 빠지면 은신 게임이 눈을 잃습니다."

## 안건 10. 테스트 방법과 통과 기준

**서지우:** "기존 이중 게이트에 문서의 게임성 기준을 얹어 최종 게이트를 확정합니다.

**박태현:** "G6~G8을 참고로 낮추면 '예쁘고 조작되는데 게임인지는 모르는' 물건이 통과합니다. 그게 제일 무서운 시나리오예요."

- **핵심 (미달 시 2주 개선 스프린트 후 재테스트, 방향 유지):** G2, G4, G6, G7, G8

**박태현:** "핵심 미달 시 '방향 유지 + 재테스트'가 보장된다면 저도 수용합니다."

> **결의 10:** 3등급 게이트 확정 — 필수(G1, G3) / 핵심(G2, G4, G6~G8: 미달 시 2주 스프린트 + 재테스트) / 참고(G5, G9: 이월) / 테스터 5인 중 2인 노트북 스피커
