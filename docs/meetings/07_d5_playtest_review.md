## 리뷰 결과 요약

D+5 회색 박스 빌드(조작·심도 3층·카메라·협곡·X-ray 스파이크)는 단계 1
Exit Criteria를 통과했다. 다만 전원 조작 테스트에서 아래 개선 결정이
나왔고, 이를 **D+5 리뷰 스프린트**(통합 순서 번호 부여)로 즉시 착수한다.

## 결의 사항

### 결의 1 — S 키는 감속이 아니라 **후진**으로 확장

- W 전진 / **S 후진** (후진 최고 속력 상한 = 전진의 50% [초기 테스트값]).
- 속도는 **부호 있는 전후 속도**로 확장 (+ 선수 방향 / − 선미 방향) —
  프로펠러 정/역회전 표현(소회의 S7 안건)의 입력값이 된다.
- 정지 상태 제자리 선회(A/D)는 유지.

### 결의 2 — 심도: 층 단위 이동 → **연속 상승·하강 + 높이 기반 3구간 판정**

- Shift = 연속 상승 / Ctrl = 연속 하강 (수직 최고 속력 = 전진의 50%
  [초기 테스트값], 키 해제 시 관성 감속 유지).
- 수면 상한·해저 하한 클램프 (수면 돌출 금지).
- 심도 "3층"의 게임 규칙(잠망경/순항/심해 — 탐지 보정·조준 게이트)은
  유지하되, 판정을 **높이 기반 3구간**으로 바꾼다. `depthChanged` 이벤트와
  구간 수 3개는 불변.
- ⚠ **마스터 플랜 §3.4·DECISIONS #2("층 단위 이동")와 상충** — 마스터
  플랜은 게이트 리뷰 전 수정 금지이므로 본 회의록과
  `docs/NEXT_SPRINT.md` 각주로 관리한다. 폐기 결정 "풀 6자유도 금지"는
  유지된다(수직은 상승·하강 축 하나만 추가, 롤·피치 없음).

### 결의 3 — 정적 충돌 도입

- 지형(벽·기둥) 통과 방지 + 밀어내기만. **피해 없음** (충돌 대미지는
  마스터 플랜 §4.1 그대로 없음).
- 충돌체 집합은 이후 은신 시야 차폐(D10~12)가 재사용한다 — 별도 집합 금지.

### 결의 4 — 어뢰 전투 조기 착수 (D6~D9 일부 전진)

- 수동 조준 진입은 잠망경 심도 전용, 자동 락온 없음 (DECISIONS #6 유지).
- 직선 주행 어뢰·최대 사거리·명중 1회 판정·재장전/보유량(combat.json)
  까지를 스프린트 범위로 한다. 리드샷 보조선·발사 지점 노출은 원래
  일정(D6~D9) 유지.

### 결의 5 — 화물선 임시 표적과 격침 연출 선행

- 렌더: 로우폴리 임시 표적·명중 폭발·기울며 침몰 연출을 준비 (판정 없음,
  상태 주입식).
- 게임플레이: 직선 왕복 화물선 시스템(1발 격침 [확정 §5.9], 침몰 시간축은
  게임플레이 소유)을 구현한다.

### 결의 6 — 해수면 표현 추가

- 저비용 평면 + 정점 파도, 수면 위/아래 배경·포그 전환. 반사·굴절·유체
  물리 없음 (§3.1·성능 예산 §12 유지).
- 협곡 벽 상단은 수중에서 수면·실루엣이 보이도록 조정 가능 — 단,
  충돌 배치와의 정합은 통합 시 단일 레이아웃로 해소한다(INT-GAME-005).

### 결의 7 — 스프린트 통합 순서 지정

각 파트는 dev(D+5 통합)를 기반으로 작업하고, 리드 계약 브랜치를 먼저
병합해 계약을 소비한다. 통합 순서 번호: [1] 리드 공통 규약(INT-CORE-002)
→ [2] 게임플레이 이동·충돌 → [3] 그래픽스 프로펠러·해수면·화물선 연출 →
[4] 툴링 조작 HUD·Pointer Lock → [5] 게임플레이 어뢰 전투 → [6] 화물선
시스템·상태 계약 정리(INT-CORE-003). 신규 수치는 params 부재 시 R7
선진행(임시값 파일 1곳 + INTEGRATION_NOTES 이관 요청)을 따른다.
