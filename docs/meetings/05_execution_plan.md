## 안건 4. 게이트 리뷰 회의 운영 방식

**서지우:** "다음 회의(D+21, 버티컬 슬라이스 게이트 리뷰)의 규칙을 오늘 미리 못 박습니다.

**규칙 1 — 새 아이디어 금지.** 게이트 리뷰에서 '이런 기능 어때요'는 발언권이 없습니다. 아이디어는 별도 백로그 문서로만 접수.

**규칙 2 — 판단은 4문 순차 통과제.**
1. **성능이 통과했는가** (G1·G2 — 정하늘 계측 데이터)
2. **조작을 이해했는가** (G3·G4·G5 — 테스터 관찰 기록)
3. **은신과 폭뢰 회피가 재미있는가** (G6·G7·G8·G9 — 테스터 인터뷰)
4. **정식 제작으로 확장할 가치가 있는가** (종합 — 전원 무기명 투표)

앞 문이 닫히면 뒷 문은 열지 않습니다. 성능이 미달인데 재미를 논하는 건 순서 위반입니다.

**규칙 3 — 데이터 없는 발언 금지.** '제 느낌엔'은 4번 문에서만 허용. 1~3번 문은 계측치·관찰 기록·인터뷰 원문만."

**한도윤:** *(우려)* "4번 무기명 투표에서 갈리면요? 4:4가 나올 수도 있는데."

**강민준:** "동수면 **속행이 아니라 중단입니다.** 절반이 확신 못 하는 프로젝트에 정식 제작 리소스를 태우지 않습니다. 동수 시 2주 개선 스프린트 후 재투표 1회, 그래도 동수면 프로젝트 보류. 냉정하지만 이게 제 역할입니다."

**정하늘:** "개발 입장에서 한 줄 추가 — 재투표 스프린트에 들어가는 조건은 '무엇을 고치면 표가 바뀌는지'를 반대표가 명시하는 겁니다. 이유 없는 반대표로 스프린트를 도는 건 리소스 낭비입니다."

> **결의 4:** 게이트 리뷰 = 새 아이디어 금지 / 4문 순차 통과제 / 1~3문 데이터 전용 / 4문 무기명 투표, 동수 시 조건부 스프린트 1회 후 재투표, 재동수 시 보류
