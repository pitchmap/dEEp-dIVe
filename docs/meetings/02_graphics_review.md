**일시:** 2026년 8월 3일 10:00 ~ 11:40
**참석자:** CEO 강민준 / 디렉터 서지우 / 게임 디자이너 박태현 / 레벨 디자이너 최윤아 / 그래픽 디자이너 한도윤 / 아트팀장 김세라 / 사운드 디자이너 이준호
**안건:** 1차 회의 결의 5번(2D 사이드뷰 확정) 재심의 — 헝그리 샤크 레퍼런스 기반 3D 사이드스크롤 재검토

## 1. 재심의 발의 — 그래픽 디자이너

**한도윤:**
"1차 회의에서 제 3D안이 철회된 핵심 논리는 세라 님의 '심해는 3D로 만들면 텅 빈 파란 화면'이었습니다. 그런데 반례를 찾았습니다. **헝그리 샤크 월드** 스크린샷을 봐주세요.

- 협곡 지형이 화면 좌우로 겹겹이 배치되어 '텅 빈 바다'가 아니라 '지형 사이를 헤엄치는' 그림이 나옵니다
- 산호, 해면, 물고기 떼가 근경을 채우고, 원경은 안개(fog)로 자연스럽게 깊이감을 만듭니다
- 그리고 중요한 건 — 이 게임, **모바일에서 돌아갑니다.** 저사양 목표와 3D는 양립 가능하다는 실증이에요

즉 문제는 '3D냐 2D냐'가 아니라 '심해를 비워두느냐 채우느냐'였습니다. 카메라는 사이드뷰로 고정하되, 세계는 3D로 만드는 **2.5D 사이드스크롤**을 재제안합니다."

## 2. 쟁점 — 각자의 입장

**아트팀장 김세라:** *(강한 반대)*
"레퍼런스는 인정합니다. 하지만 두 가지를 지적하겠습니다.

첫째, **헝그리 샤크는 연안 게임이고 우리는 잠수함 게임입니다.** 저 스크린샷은 수심 20~30m의 밝은 연안이라 산호와 협곡이 예쁘게 나오는 거예요. 우리 게임의 무대는 수심 100m 이하 — 잠수함이 폭뢰를 피해 숨는 곳은 원래 캄캄하고 비어 있는 곳입니다. 심해 스테이지에 가면 결국 '파란 안개 속 잠수함'으로 돌아갑니다.

둘째, **아트 비용이 문제입니다.** 헝그리 샤크의 저 밀도는 대형 스튜디오가 수년간 쌓은 에셋 라이브러리의 결과예요. 우리 인원으로 협곡·산호·어군·해면을 3D로 저 밀도까지 채우려면 2D 대비 최소 2.5배 기간을 잡아야 합니다."

**한도윤:**
"첫째 지적에는 이렇게 답하겠습니다 — 심해가 비어 보이는 건 오히려 연출로 씁니다. 연안 스테이지는 헝그리 샤크처럼 화려하게, 심해 스테이지는 서치라이트와 발광 생물만 남기고 어둡게. **'밝고 안전한 곳 → 어둡고 위험한 곳'의 대비** 자체가 공포 연출이 됩니다. 비어 있는 게 결함이 아니라 의도가 되는 거죠."

**레벨 디자이너 최윤아:** *(3D 지지로 입장 변경)*
"1차 회의에서는 세라 님 편이었는데, 이 스크린샷을 보고 생각이 바뀌었습니다. 레벨 디자인 관점에서 3D 협곡 지형은 제가 설계한 '해협 스테이지'와 정확히 맞아떨어집니다. 좁은 협곡 사이로 소나를 피해 숨고, 지형 뒤에 어뢰 사선을 가리는 플레이 — 2D 평면보다 3D 지형이 압도적으로 표현력이 좋아요. 특히 헝그리 샤크처럼 **전경 지형과 배경 지형을 여러 겹으로 두면** 같은 에셋을 재배치해서 맵 6개 분량이 나옵니다. 세라 님이 걱정하신 에셋 비용은 재사용 설계로 상당 부분 상쇄됩니다."

**게임 디자이너 박태현:** *(조건부 반대)*
"방향은 좋은데 하나가 무너집니다. 1차 회의에서 채택한 **'배 안에 사람이 산다' — 승무원 4명이 보이는 내부 단면**은 어떻게 됩니까? 3D 외부 뷰로 가면 잠수함은 다시 '껍데기'가 되고, 윤아 님이 직접 지켜낸 정체성이 사라져요. 이거 해결 없이는 반대입니다."

**한도윤:**
"내부 단면을 UI로 격하하지 말고 **화면 하단 1/4에 상시 표시되는 단면 패널**로 유지하는 안은 어떨까요? 위 3/4은 3D 외부, 아래 1/4은 2D 내부 단면. 침수·화재·승무원 이동이 계속 보입니다."

**김세라:**
"그건 최악입니다. 화면이 두 동강 나고, 아트 스타일도 3D와 2D가 충돌해요. 차라리 이렇게 하죠 — **피격당하거나 스킬을 쓸 때만 잠수함 헐(hull)이 반투명해지면서 내부가 비쳐 보이는 X-ray 연출.** 헝그리 샤크식 3D 세계관 안에서 내부 가시화를 '순간 연출'로 해결하는 겁니다. 평소엔 외부 3D의 몰입감, 위기 순간엔 내부의 드라마."

**박태현:**
"…X-ray 연출이면 조건 충족입니다. 반대 철회합니다."

**사운드 디자이너 이준호:**
"한 가지만 짚겠습니다. 3D로 가면 사운드도 3D 패닝이 필요해집니다. 폭뢰가 왼쪽 위에서 떨어지면 소리도 왼쪽 위에서 나야 해요. Web Audio API 패너로 가능하고, 오히려 1차 회의의 '사운드 = 1차 정보' 원칙이 3D 공간에서 더 강력해집니다. 저는 찬성입니다."

**CEO 강민준:**
"비용 얘기로 돌아갑시다. 세라 님, 2.5배라고 하셨는데 윤아 님의 에셋 재사용 설계를 반영하면?"

**김세라:**
"…재사용 전제, 그리고 심해 스테이지를 '어둡게 비우는' 연출을 공식 채택한다면 1.5배 선까지 봅니다. 다만 조건이 있습니다 — **아트 검증 게이트**를 요구합니다. 3주 안에 협곡 씬 하나를 목표 사양(내장그래픽 노트북, 60fps)에서 돌리는 버티컬 슬라이스를 만들고, 실패하면 2D안으로 즉시 롤백. 이 조건이면 반대를 거두겠습니다."

**서지우:**
"공정한 조건입니다. 받아들이죠."

## 3. 최종 결의안

| # | 항목 | 결정 사항 |
|---|------|-----------|
| 1 | 그래픽 방향 | 1차 결의 5번 **수정**: 2.5D 사이드스크롤 3D로 변경 (카메라 사이드뷰 고정, 세계는 3D). 레퍼런스: 헝그리 샤크 월드의 지형 밀도 |
| 2 | 공간 연출 원칙 | 연안 = 협곡·산호·어군으로 밀도 높게 / 심해 = 의도적으로 어둡고 비운 공포 연출 (서치라이트 + 발광 생물). '밝음→어둠' 대비를 공식 연출 문법으로 채택 |
| 3 | 내부 가시화 | 상시 단면 패널 기각. **피격·스킬 사용 시 X-ray(헐 반투명) 순간 연출**로 승무원 4명 가시화 유지 |
| 4 | 에셋 전략 | 전경/배경 다층 재배치로 지형 에셋 재사용. 신규 제작 최소화 |
| 5 | 사운드 | 3D 패닝 도입 (Web Audio API). 폭뢰·소나의 방향 정보를 공간 음향으로 전달 |
| 6 | **검증 게이트** | **3주 내 버티컬 슬라이스**: 협곡 씬 1개, 내장그래픽 노트북 60fps 달성. 실패 시 2D안(1차 결의)으로 무조건 롤백 |
| 7 | 차기 회의 | 버티컬 슬라이스 리뷰 회의에서 최종 확정 |

**서명:** 참석자 전원 합의 (아트팀장 조건부 동의 — 검증 게이트 전제 / 게임 디자이너 반대 철회 — X-ray 연출 전제)

## 부록 — 리스크 로그
- **R1:** 3D 물 셰이더가 내장그래픽에서 병목 → 정점 애니메이션 + 단색 그라데이션으로 대체 준비
- **R2:** X-ray 연출 구현 난이도 → 실패 시 대안: 피격 시 화면 코너에 단면 팝업 (2초)
- **R3:** 심해 스테이지가 '비어 보임'이 아니라 '심심함'으로 받아들여질 위험 → 플레이테스트에서 심해 체류 시간 데이터로 판단
