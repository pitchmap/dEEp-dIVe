# docs/meetings — 회의록 보관소

## 원칙

1. **현재 구현 기준은 `docs/deep_dive_master_plan.md` 하나뿐이다.**
   회의록과 마스터 플랜이 충돌하면 마스터 플랜을 따른다.
2. **회의록은 변경 이력 확인용 역사 기록이다.** "왜 이렇게 결정됐는가"를
   추적할 때만 참조한다.
3. **이전 회의의 폐기된 결정은 구현 근거로 사용할 수 없다.**
   예: 2D 사이드뷰(1차), 2.5D 사이드스크롤(2차), 자동 조준 우선(4차),
   3택 1 강화 카드(4차) 등은 이후 회의·마스터 플랜에서 폐기·컷되었다.
   폐기 목록은 마스터 플랜 부록 B·C 참조.
4. 마스터 플랜 내부에서 내용이 충돌하면 **가장 최근 회의에서 확정된 결정**을 따른다.
