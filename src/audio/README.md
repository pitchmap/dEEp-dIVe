# src/audio — 오디오 배관 (빌드·툴 파트 소유)

이 디렉터리는 **빌드·툴 담당(역할 프롬프트: `prompts/TOOLING.md`)의 소유 영역**이다.
단, 여기서 담당하는 것은 **배관(Web Audio API 연결·재생·패닝·지연 측정)뿐**이다.

## 책임 경계 [확정 — 마스터 플랜 §7.2]

- **판정 로직(게임플레이 파트)이 타이밍의 주인이다.** 폭뢰 '풍덩→3초→폭발'의
  3초를 재는 것은 `DepthChargeSystem`이며, 오디오는
  `depthChargeEnteredWater`/`depthChargeExploded` 이벤트에 동기화만 한다.
- 오디오 지연이 100ms를 넘으면 지연 보상 오프셋을 적용하고, 해결 불가 시
  S1 버그로 처리한다 (보호 목록 '폭뢰 사운드 동기화').

## 현재 구현 상태 (단계 0)

- `WebAudioSystem.ts` — `AudioSystem` 계약 구현: 사용자 제스처 기반 unlock,
  마스터 GainNode 버스, PannerNode → 버스 연결, 카메라 기준 리스너 자세 갱신.
  아직 어떤 사운드도 재생하지 않으며 Game 조립은 D3 이후(리드 승인 경유).

## 여기에 구현될 것 (D3 이후)

- 이벤트 구독 기반 재생·3초 동기화 (지연 측정·보상 오프셋 포함)
- 사운드 스트리밍 후속 로드 (초기 번들 15MB 게이트 보호)
- 모노 생존 정보(핑 간격·음높이) 재생 경로 — 노트북 스피커 대응

## 규칙

- 사운드 세트(에셋)는 사운드 디자이너 산출물(D+10)이며 `assets/audio/`에 들어온다.
- 게임 판정 시간의 소유권을 갖지 않는다.
